== Business Directory Plugin for WordPress ==

The Business Directory Plugin is the easy WP directory plugin for building a business directory or member directory without writing a line of code. Run a restaurant directory for your town, or a staff directory for your own team, and it's live in minutes.

If you're not a developer, no problem. This WordPress directory plugin doesn't require any coding knowledge. Activate it, then click the setup notice's "Create required pages for me" button, and your directory page is live with the [businessdirectory] shortcode already in place. Need to show listings somewhere else, too? Drop the [businessdirectory-listings] shortcode into any page to display a specific category or tag, or add the Featured, Latest, Random, or Search widgets to any sidebar. See the [full shortcode reference](https://businessdirectoryplugin.com/knowledge-base/shortcodes/?utm_source=wprepo&utm_medium=link&utm_campaign=liteversion) for everything else you can do.

== An Easy WordPress Directory Website Builder ==

Already have a list of businesses, staff, or members in a spreadsheet? Import it in one upload instead of typing every entry by hand. Add whatever fields your directory needs, like a phone number, hours, a price range, or a photo.

Take the listings you want and build almost any kind of directory: a real estate listings site like Zillow, a local business directory like Google Business Profile, a services marketplace like Thumbtack, a connections directory for an address book, a web directory for curated local links, or a book review site like Goodreads. It's a listing manager and directory website builder for whatever you build.

== Accept Payments for Directory Listings ==

Choose how your directory earns. Offer free listings or paid plans, one-time or recurring, and assign different plans to different categories so premium listings and free listings live side by side. Add featured or sticky placement as a paid upgrade. Stripe and Authorize.net both process real payments in the free plugin. You don't need a paid plan for either one. Stripe comes with pay-as-you-go pricing (3% per-transaction, on top of Stripe's own fees) until you upgrade to a paid plan. Authorize.net has no per-transaction fee, ever. Every plan and price stays fully in your control from your own WordPress dashboard.

= Will this plugin slow down my site? =

No. This WordPress directory plugin only loads its scripts and styles on your actual directory pages, not site-wide, so the rest of your site isn't affected.

= What happens to my listings if I deactivate or delete the plugin? =

Nothing. Your listings are just WordPress posts in your own database. Deactivating or even deleting the plugin from Plugins -> Installed Plugins leaves them in place, along with your categories and settings. Data is only removed through the plugin's separate Uninstall tool, which requires its own confirmation step and warns you before deleting anything.

= Does this directory plugin scale as my listings grow? =

Yes. Listings paginate automatically, categories and tags keep a large directory organized and searchable, and CSV import/export handles bulk listing management without entering every record by hand.

= Can I accept paid and free listings? =

Yes. Create a plan priced at $0.00 alongside one or more paid plans to offer free and paid listings side by side in the same directory.

= Do you have video tutorials for building WordPress directories? =

Yes. Find them on the [YouTube channel](https://www.youtube.com/channel/UCfwZGdxFv6bJIfGMZHDYNFA).

= Will this plugin work with my theme? =

Yes. This WP directory plugin displays through shortcodes and widgets instead of requiring a specific theme, so it works with any well-built WordPress theme.

= Can I translate my web directories? =

Yes. User-provided translations ship under the /languages folder, already available in:

* Spanish
* French
* German
* Russian
* Italian
* Polish
* Arabic
* Swedish
* Dutch

See the guide on [translating the Business Directory Plugin into another language](https://businessdirectoryplugin.com/knowledge-base/translating-bd-other-language/?utm_source=wprepo&utm_medium=link&utm_campaign=liteversion) for any language not yet covered, or [translate it yourself using Loco Translate](https://businessdirectoryplugin.com/knowledge-base/translating-business-directory-plugin-using-loco-translate/?utm_source=wprepo&utm_medium=link&utm_campaign=liteversion).

= Is this plugin compatible with WordPress Multisite (WPMU)? =

Yes, with one restriction: do not "network activate" the plugin, since that would share the database across every site. Activate it only on the sub-sites that need it, under Plugins -> Add New as the Administrator user. Don't activate it as the "super admin."
